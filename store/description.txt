TabPilot is a window and tab manager for Chrome power users. See every open tab across all windows in one dashboard, reorganize with drag-and-drop, find duplicates, save sessions as projects, and optionally let AI suggest groupings.

--- DASHBOARD ---

Open the TabPilot dashboard to see a bird's-eye view of every Chrome window and tab. Each window appears as a column showing tab titles, favicons, audio indicators, and suspended status. The dashboard updates in real time as you open, close, or navigate tabs. Chrome tab groups are shown with their colors and names.

--- SIDE PANEL ---

TabPilot also runs as a Chrome side panel for the current window. Search tabs, filter to tabs playing audio, suspended tabs, or ungrouped tabs, and close tabs without leaving the page you are on.

--- ORGANIZE CHROME'S TAB STRIP ---

Works with Chrome's own tabs, including native vertical tabs. From the side panel:
- Group: put ungrouped tabs into Chrome tab groups by site, with a consistent color per site. Your custom rules (domain, keyword, or regex) can send matching tabs to a named group instead.
- Sort: order tabs and groups alphabetically or by site.
- Collapse: collapse every group except the one you are working in.
- Undo: put the strip back exactly as it was.
Groups you created yourself and pinned tabs are left alone.

--- DRAG AND DROP ---

Reorder tabs within a window or drag them to another window. Drop a tab onto the "new window" zone to split it out. Use Ctrl+click or Shift+click to select multiple tabs, then close, mute, suspend, or move them to a new window in bulk. Bulk actions can be undone.

--- SESSION PROJECTS ---

Save your current set of windows and tabs as a named project and reopen it later. Export projects as JSON. Export your currently open windows as JSON or CSV.

--- TAB SUSPENSION ---

Suspend tabs to free RAM and CPU using Chrome's native tab discarding. Suspended tabs keep their place, title, and favicon and reload when you click them. TabPilot can also auto-suspend tabs after a configurable period of inactivity.

--- AI GROUPING (OPTIONAL) ---

Connect your own OpenAI or Anthropic API key to let TabPilot suggest tab groupings. The AI receives only tab titles and domain names — never full URLs, page content, cookies, or browsing history. You review the suggestions and apply them as Chrome tab groups with one click.

--- DUPLICATE DETECTION ---

Find duplicate tabs across all windows using three detection modes:
- Exact URL match
- Canonical URL (ignores tracking parameters like utm_source)
- Similar titles on the same site

Close duplicates in bulk and undo if you change your mind.

--- SEARCH AND SORT ---

Live-filter all tabs by title or URL. Sort alphabetically or by domain.

--- KEYBOARD ---

Ctrl+Shift+M (Cmd+Shift+M on Mac) opens the dashboard. Press / to search, Esc to clear, Ctrl+Z to undo. The dashboard shortcut can be changed at chrome://extensions/shortcuts.

--- PRIVACY ---

TabPilot has no accounts, no analytics, no telemetry, and no servers. Saved sessions are stored locally on your device; settings use Chrome's built-in storage sync.

The optional AI feature sends only tab titles and domain names to the API provider you configure with your own key. You can use TabPilot without the AI feature entirely.

TabPilot is open source (MIT): https://github.com/ankitksharma/tabpilot
Privacy policy: https://ankitksharma.github.io/tabpilot/privacy.html

--- PERMISSIONS EXPLAINED ---

- tabs: Read tab titles and URLs to display in the dashboard
- tabGroups: Read and create Chrome tab groups
- storage: Save settings and session projects
- alarms: Schedule auto-suspension of inactive tabs
- sidePanel: Render the side panel UI
- contextMenus: "Open Tab Manager" item in the toolbar icon's right-click menu
- declarativeNetRequest: Remove the Origin header on requests to the AI APIs you configure (required by their CORS policies)

Host permissions for api.openai.com and api.anthropic.com are used only when you configure an API key for the AI grouping feature.

--- WORKS WITH ---

Chrome, Edge, Brave, and other Chromium browsers. Manifest V3.
Note: browsers that keep sleeping tabs outside Chromium's tab list (for example Dia and Arc) only expose loaded tabs to extensions, so TabPilot can only show those.
