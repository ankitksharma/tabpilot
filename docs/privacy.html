Privacy Policy

TabPilot — Window & Tab Manager for Chrome
Last updated: October 9, 2026

Summary

TabPilot does not collect any personal data. The developer operates no servers and receives no data from the extension. Extension data is kept in Chrome's built-in extension storage on your device (and, for settings, in Chrome's own sync if you have Chrome Sync enabled).

Data Collection

TabPilot collects no user data. Specifically:

  • No personally identifiable information
  • No browsing history
  • No page content
  • No cookies or authentication tokens
  • No analytics or telemetry
  • No crash reports

Data Stored by the Extension

TabPilot stores the following on your device using chrome.storage.local:

  • Saved session projects (window and tab URLs/titles)
  • Duplicate-detection results and AI grouping suggestions
  • AI provider configuration (provider choice and API key, if configured)

TabPilot stores the following using chrome.storage.sync, which Chrome synchronizes across your signed-in browsers through your Google account if Chrome Sync is enabled:

  • User preferences (such as the auto-suspend timer)
  • Custom routing rules for tab grouping

TabPilot never sends this data to the developer or any server operated by the developer. Export saves a file to your local filesystem only when you choose to export.

AI Feature (Optional)

TabPilot includes an optional AI-powered tab grouping feature. If you choose to use it:

  • You provide your own API key for OpenAI or Anthropic, or select Chrome's built-in on-device AI where available (no data leaves the browser)
  • TabPilot sends only tab titles and domain names (no full URLs) to the AI provider you configure
  • No page content, cookies, browsing history, or personal data is transmitted
  • API calls go directly from your browser to the provider — TabPilot has no intermediary server
  • Your API key is stored locally and never shared with TabPilot or any third party

You can use TabPilot without the AI feature. No data is sent to any external service unless you explicitly configure an AI provider.

Permissions

TabPilot requests only the Chrome permissions necessary for its features:

  • tabs — read tab titles and URLs to display in the dashboard
  • tabGroups — read and create Chrome tab groups
  • storage — persist settings and saved sessions locally
  • alarms — schedule auto-suspension of inactive tabs
  • sidePanel — render the side panel UI
  • contextMenus — add "Open Tab Manager" to the toolbar icon's right-click menu
  • declarativeNetRequest — remove the Origin header on requests to the AI APIs you configure (CORS)

Third-Party Services

TabPilot does not integrate with any third-party analytics, advertising, or tracking services. The only requests TabPilot itself makes are to AI API endpoints (OpenAI or Anthropic) when you explicitly configure and use the AI feature with your own API key. To display tab icons, the dashboard loads each open tab's favicon from the address the website provides, the same way Chrome's tab strip does.

Data Sharing

TabPilot does not sell, share, or transfer any user data to third parties. There is no user data to share.

Children's Privacy

TabPilot does not knowingly collect any information from children under the age of 13.
